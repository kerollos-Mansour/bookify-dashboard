# Logo Files Note

The sidebar and header reference logo files that need to be added to the project:

- `/public/images/logo/logo.svg` - Light mode full logo
- `/public/images/logo/logo-dark.svg` - Dark mode full logo
- `/public/images/logo/logo-icon.svg` - Collapsed sidebar icon

## To Add Logos:

1. Copy the logo files from the reference project at `like this/public/images/logo/`
2. Place them in `public/images/logo/` directory
3. Or create your own Bookify logos and place them in the same location

The logos are referenced in:

- `layout/AppSidebar.tsx` (lines 311-336)
- `layout/AppHeader.tsx` (lines 86-100)

You can temporarily use placeholder images or text until the actual logos are ready.
